Accommodations

Gives one student extra time or extra violations. This makes a code for the student and a line for the accommodations list in config.js. The line holds only a hash, so config.js doesn't show who has an accommodation, and the code works only with that student's ID.

Extra time and Forms: the time duration and end date in Forms apply to everyone. For an exam with extra time, set them in Forms to the longest time any student gets (the exam page still ends each student's session on time), or give those students a copy of the form as a separate exam.
