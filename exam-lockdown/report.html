How to get the two files

  1. Forms results: open the form in Microsoft Forms, go to Responses and select Open results in Excel (or Download a copy). Save the .xlsx file.
  2. Exam Events: open the Exam Events list in SharePoint and select Export > Export to CSV. Use the full list or a view that shows all columns, not a filtered one.

If the Forms times are off by an hour or more from the log, the page offers a fix under the summary. You can also set Forms time offset yourself.
